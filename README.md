## What you'll find here

A collection of open source QoL Cheat Engine scripts I made for Dark Souls 3. 

Just click on the script of interest, copy (Ctrl+C) the whole text contents, and paste (ctrl+V) into your actively opened CE table window! The script should appear under your last blue highlighted CE entry.


## Available scripts

### - [🔗 Blue Sentinel desync bug fix](https://github.com/dan007d/dan007d/blob/main/Fix_BlueSentinel_DesyncBug.txt)
Patches a bug causing players to always become desynced to each other when playing in long, uninterrupted multiplayer sessions.
The patch is active as long as the script is kept activate!

### - [🔗 No BS kick on estus cancel](https://github.com/dan007d/dan007d/blob/main/NoEstusCancelBSKick.txt)
Prevents people's Blue Sentinel from detecting your estus cancels, avoiding unfair kicks. 
It works as long as the script is kept active!
